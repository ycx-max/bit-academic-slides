# 公开版版式参考

查看 assets/slide-01.png 至 slide-08.png。公开版保留绿白封面、原生母版、校徽、章号和页脚，示例只提供布局教学内容，没有个人署名、课程实拍或实验结果。

| 页面 | 主题 | 可采用的构图 |
|---|---|---|
| 1 | 封面 | 绿白品牌区、两行标题、汇报信息 |
| 2 | 研究问题 | 大图与简洁问题定义 |
| 3 | 方法流程 | 横向流程与输入输出 |
| 4 | 模型结构 | 架构图、关键假设与公式 |
| 5 | 实验设计 | 公平对照、原生表格 / 图表 |
| 6 | 结果证据 | 大图与简短解读 |
| 7 | 复现演示 | 操作顺序与真实界面截图 |
| 8 | 结论讨论 | 结论、边界与下一步问题 |

表中的构图是选择建议；根据图片比例和内容调整，不固定页数。

正文区域通常为 1280×720 坐标中的 x=48–1237、y=113–637，页脚约从 y=650 开始。双栏可用 x=51–625 与 x=665–1230；方法流程可横向展开。更多颜色、字体和几何见 design-system.md。

需要空白页时用 assets/layout-scaffold.pptx 和 scripts/make_scaffold.py。填充 Cover_2 / Cover_3 / Cover_4 与 Header_9 / Header_5。占位符继承布局几何时，不要只赋 width：应同时保存并设置 left、top、width、height，避免新建零坐标的变换。模板已包含动态页码，不要重复叠加页码。
